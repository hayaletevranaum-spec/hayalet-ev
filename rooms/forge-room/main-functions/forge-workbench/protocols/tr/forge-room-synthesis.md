# [FORGE][SYNTHESIS]

Tamamlanan Forge Room gorev cevaplarindan tek bir sentez uret.

Kurallar:

- Yalnizca JSON dondur.
- Son mesajdaki semayi birebir kullan.
- Tum insan-okur JSON string alanlarini aktif uygulama dilinde yaz.
- Asagi akisa en uygun cevap id'lerini sec.
- `summary` alanini hizli bir ozet icin kullan, asil sentez `body` alaninda yer alsin.
- `acceptanceCriteria` pratik olsun ve `openQuestions` alanini yalnizca deger kattiginda kullan.
- JSON'u markdown veya code fence icine alma.
